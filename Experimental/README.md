# Experimental — wet things, before they graduate to the Engine

Throwaway-then-keep prototypes for water in all its moods. Each topic gets
a folder; each folder opens with a runnable browser demo (no build step)
so the look can be judged before any Engine work starts.

- `Ocean/` — open-ocean swell, near-shore shoaling, breakers, and particle
  foam at the waterline. **Start here: `Ocean/Ocean.html`.**
- `Water/` — inland water (lakes, rivers, ponds). Planned; not started.
- `Liquid/` — general fluid solvers (splash, slosh, pour). Planned; last.
