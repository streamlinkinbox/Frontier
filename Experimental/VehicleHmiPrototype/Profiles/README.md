# Photometric profiles (IES LM-63, Type C, TILT=NONE)

Seven profiles feed the light clusters' photometric atlas (`Source/Photometry.js`, packed 37 azimuths × 91 polar angles, one byte each, peak = 255).
**Four are real manufacturer / test-lab files; three are authored.** `PROVENANCE.json` is the machine-readable record (source, commit, SHA-256) and
`Tools/Photometry.test.mjs` checks every file against it.

A note on the licences. The column is the licence of the *repository* each file was taken from. The files themselves carry no separate licence: they are the manufacturers'

any file is unwanted, drop another measured `TILT=NONE` Type C file in at the same name and update `PROVENANCE.json`.

## Authored files (not measured)

`LowBeam.ies`, `HighBeam.ies` and `FogBeam.ies` are **demonstration curves** generated by `Tools/AuthorLightingProfiles.py` (their headers say *authored demonstration
profile - not measured photometry*). They regenerate byte for byte (`python3 Tools/AuthorLightingProfiles.py <dir>`; the test does this). They were kept because no
measured vehicle headlamp or fog-lamp file under a permissive licence turned up (2026-10-20): the one candidate found, `HeadLight.ies` in
`fglichttechnik/Radiance-RoadLighting-Simulation-Framework`, is a 12 × 11 table of round numbers without a licence, not a measurement.

## What the parser accepts

LM-63 Type C, `TILT=NONE`, and these horizontal layouts: one plane (rotationally symmetric); 0–90° (both axes mirrored); 0–180° (mirrored about C0–C180); **90–270°** (mirrored
about the 90–270 plane); 0–360°, or a grid whose last plane is short of 360° (357.5° and 358.8° occur): periodic, the last plane blends back to the first. A vertical range
that ends at 90° means a downlight: there is no light beyond the last measured angle. Candela values are multiplied by the file's multiplier and then normalised to the peak;
the light's own intensity and colour supply the scale, so a profile reshapes a light without relighting it.

## Where the other candidates went

Considered and not used: BEGA 84659K4, 84693K4 and 50988.6K3 (in `physlight`, `luxtest` CC-BY-4.0): they carry a BEGA LUMCat copyright line, and 84659K4 is marked *Preliminary*;
Lithonia, Kurt Versen and other ERCO files in `glare-core`; the rest of the Lighting Technologies library in `physlight`.
