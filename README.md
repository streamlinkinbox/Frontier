# Frontier — The Crucible

A cinematic, playable sci-fi motorball circuit inspired by the supplied stadium references. The experience opens on a photorealistic steel half-pipe track briefing, then transitions into a procedural Three.js arena with steep banking, hazard chevrons, guardrails, floodlights, grandstands, racers, sparks, boost, three camera modes, and a cinematic tour.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown by Vite.

## Controls

- **W / Up Arrow** — accelerate
- **S / Down Arrow** — brake
- **A/D or Left/Right** — steer
- **Shift** — boost
- **C** — cycle chase, deck, and arena cameras
- **R** — reset the run
- **Esc** — return to the circuit briefing

Touch controls appear automatically on narrow screens.

## Production build

```bash
npm run build
npm run preview
```
