# Frontier

Open-world game project.

## SDF Terrain Studio

See [`sdf-terrain/`](sdf-terrain/) — realtime volumetric (SDF, no heightmaps)
terrain generator with physics-based particle erosion, node graph, paintable
rain, and procedural satellite-style surfacing. Serve it with any static
server: `cd sdf-terrain && python3 -m http.server 8080`.
