# Frontier

## Engine modules

- [`engine/fluid`](engine/fluid/README.md) — real-time WebGPU water: GPU shallow-water simulation
  (sea and swell, rivers, puddles, mud) at two coupled resolutions, camera-adaptive water mesh,
  caustics, spray, buoyancy, two-way vehicle interaction and terrain sculpting. Drivable demo:
  serve the repo root and open `engine/fluid/demo/`.
