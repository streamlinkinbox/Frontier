# Frontier

## RoadForge

`RoadForge/` is a standalone WebGPU road-network generator (spline roads, merged single-mesh intersections, bridges, underpasses, tunnels, interchanges, railways with trains, procedural PBR surfaces, street furniture, AI traffic) with a FrontierEditor-style layer stack + inspector UI. Open `RoadForge/RoadForge.html` in a WebGPU browser, or read `RoadForge/README.md`.
