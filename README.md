## SolidArc

The standalone C++20 NURBS/B-rep modelling tool lives at
`Editor/AuthoringTools/Modelling/SolidArc`. The current direct-modelling increment is Phase 34:
face-to-face lofts between two solids, fixed-topology face/edge/vertex tweaks, and single-edge
chamfers with transactional refusals for unsupported geometry.

Run `Tools/Build/CheckSolidArc.sh` for the focused dependency-free verification gate.
