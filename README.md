# D-DAY — The Atlantic Wall

A low-poly D-Day driving assault. You are between a rising tide and the Atlantic Wall. Reach the wall.

## Play

Serve the folder (ES modules) and open the page:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

Then open `http://localhost:8080`.

**W A S D** or arrows to drive, **Shift** / **Space** to brake.

## Battlefield

- Winding dirt track from Sword Beach inland (~1.6 km), not a straight shot
- Rising ocean tide behind you
- Concertina / barbed-wire belts, Czech hedgehogs, barricades, dragon’s teeth
- Anti-personnel mines and anti-tank mines marked with an **X**
- Static tanks (some wrecks), earth mounds, trenches, sandbags, timber crossings
- Machine-gun bunkers and sandbag nests firing tracer rounds (not lasers)
- Low-poly bombers that walk bombs onto the sedan
- Giant Atlantic Wall finish

Low-poly sedan (Sentra-like, outward normals), clean vertex-coloured terrain.
