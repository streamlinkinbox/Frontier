# Frontier — Dustline Mine Run

A self-contained browser prototype for the Dustline underground mine race. Open `app/index.html` in a browser or serve the `app/` directory with any static HTTP server.

## Controls

- `WASD` or arrow keys — drive and steer the Boxcar MK-IV
- `Space` — boost while accelerating
- `R` — reset the run
- `C` — toggle cinematic HUD

The mine is rendered as a real perspective WebGL scene with custom 3D meshes: intersecting grooved service roads, roof supports, light cones, rock field, traffic carts, and a chase-camera player vehicle. It uses no external engine or build step.
