# Replay temporal visibility audit — 2026-10-29

## Scope and evidence level

This is a test-only Vulkan fixture, not a Frontier production-scene render. It uses the existing one-bounce material-reuse replay with unchanged estimator math, an added overhead area emitter, an opaque quad occluder, four moving-receiver submissions, and same-seed prior/current path pairing. Runtime was measured on the locally built SwiftShader software Vulkan device (Subzero). No production shader, reservoir default, or renderer behavior was changed.

The direct fixture uses 32 independent seed cohorts × 512 checkerboard pixels per mode (16,384 direct-ray records per mode). The preserved no-emitter baseline uses 128 cohorts × 512 pixels per mode (65,536 records per mode). The smaller direct fixture still produced over a thousand blocked samples per mode and over a thousand visibility transitions; the two sample counts should not be conflated.
