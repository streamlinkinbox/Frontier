# SolidArc edge path walkthrough — Ctrl+click an unpicked edge while edges are picked (Blender's pick shortest path):
# the edges from the active (last picked) edge to the clicked one join. Inspector › Edge path: Along loop keeps to a
# loop holding both edges (an edge loop, a face rim or a tangent chain) and never cuts across the body, Other side takes
# the far way round a closed loop, Whole loop the whole loop, Shortest the least total length over any edges.
# Ctrl+click on a picked edge still removes it (Plasticity).
# Run: SolidArcCapture --specimen --reset-files --recovery …/EdgePathRecovery.solidarc
#      --document …/EdgePath.solidarc --script Exhibits/SolidArc/Code/Scripts/EdgePathWalkthrough.txt
# Closed forms on the 2 × 1 × 1 box: front-top → back-top round the top rim 2 + 1 + 2 = 5 (either side), the whole
# rim 6; front-top → right-bottom shares no loop (refused along a loop), shortest 2 + 1 + 1 = 4 down the front-right edge.

# The Drawing options panel, shown by default while a drawing tool is active, covers the top right of the
# viewport where some of these clicks land: hide it first (Inspector › Surface tracing › Drawing options).
frames 2
click @DrawingOptions
frames 2

snap grid on

frames 2

frames 2
key F
frames 2
key E
frames 2

key A Ctrl
type 1

key Enter
frames 2

expect volume ~ 2
