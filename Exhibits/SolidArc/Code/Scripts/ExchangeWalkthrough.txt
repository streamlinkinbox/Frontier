# SolidArc STEP / STL exchange walkthrough — Export… writes the selected bodies (else every shown body) beside the
# document as STEP AP214 (exact B-rep, millimetres) or binary STL; Save as… (Ctrl+Shift+S) exports instead of saving
# when the name ends in .step / .stp / .stl and Open… (Ctrl+O) imports a .step / .stp file into the document, as
