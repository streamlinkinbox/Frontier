# SolidArc panel-assembly walkthrough (vehicle plan V5–V7): ① the synthetic bonnet is lofted as two panels, the
# rear one G2 to the front (G2 button), Alt+X (Plasticity mirror, gizmo x) mirrors both through x = 0 — the SpaceCurves
# ending on the plane are re-fitted to leave it along x̂, so the halves sew G1 into one 4-panel sheet; Close refuses
# the open, non-planar rim. ② The synthetic pod (5 planar half hoops): loft → Alt+X → Close → a sound solid.
# ③ The bonnet network (6 sections + 4 spines that cross): L builds one Gordon panel instead of a loft.
