# SolidArc blueprint-modelling walkthrough (vehicle surfacing, blueprint study): Import curves… reads the BMW M3
# (E90) trace (Experimental/VehicleSurfacing/Samples/BmwM3E90Sections.toml: 24 faired half sections + 3 [[ImagePlanes]]),
# the blueprint shows behind the curves in the Right / Top / Front views (parallel projection), a left-drag box picks all 24
# sections in station order, L lofts them, Alt+X mirrors, Close caps the ends → sound solid; four x-axis cylinders
# (Construct · Axis x · Difference) cut the wheel arches through the body sides.
# The blueprint picture is third-party and not committed: place a copy at _ClaudeScratch/Blueprint/BmwM3E90.jpg (see
# Experimental/VehicleSurfacing/Samples/BmwM3E90Calibration.toml); without it the planes refuse and the geometry is unchanged.
# Run from the repository root: SolidArcCapture --specimen --reset-files --recovery …/BlueprintRecovery.solidarc
#      --document …/Blueprint.solidarc --script Exhibits/SolidArc/Code/Scripts/BlueprintModellingWalkthrough.txt
# Arches: wheel centres y 0.805 / 3.566 (axles), z 0.33; r 0.37; from x = ±0.62 (inside the tyre) 0.5 outward.
