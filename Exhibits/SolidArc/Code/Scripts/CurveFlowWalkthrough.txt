# SolidArc point-on-curve + Flow walkthrough. Request: "need a way to … add point on the curve without changing the shape;
# and move the points; + … draw a curve; then project another 2d shape onto it; eg take a Y and project it on a nurbs
# curve; so the Y shape will follow the Y curve … [we select 1st curve and curve to project then we go to inspector and
# press project]; … control must snap to points only … Alt must snap along the curve; also move construction history to
# the inspector tab".
# Point (V, bottom toolbar) adds a point where the curve is clicked (same shape) and picks it, so a drag moves it. Flow
# (Inspector › Curves) bends the picked shapes along the first picked curve into a new sketch. History is an Inspector tab.
# Run: SolidArcCapture --specimen --reset-files --recovery …/CurveFlowRecovery.solidarc
#      --document …/CurveFlow.solidarc --script Exhibits/SolidArc/Code/Scripts/CurveFlowWalkthrough.txt
