# SolidArc x-ray walkthrough — Alt+Z (Plasticity viewport:toggle-x-ray) ghosts the faces at 45 % and draws the
# hidden part of every edge as a pale stroke that stays pickable: hover, click and box selection reach through the solid.
# Run: SolidArcCapture --specimen --reset-files --recovery …/XRayRecovery.solidarc
#      --document …/XRay.solidarc --script Exhibits/SolidArc/Code/Scripts/XRayWalkthrough.txt
# Bracket specimen: block 4 × 2.5 × 1, boss r 0.5 at (1, 1.25), hole r 0.3 at (3, 1.25), Fillet1 r 0.25 on the right top
# edge, Chamfer1 0.2 on the left top edge — 11 faces, 24 edges, volume 4·2.5·1 + π·0.5²·0.75 − π·0.3² − (1 − π/4)·0.25²·2.5
# − ½·0.2²·2.5 = 10.22278. From the isometric view the back-bottom edge (y = 2.5, z = 0) lies behind the solid.

# Placement snapped to the 0.1 grid, as these checks were written for (free placement is the default since ⑮ of Snapping).
snap grid on

# ① the bracket, opaque, mode 2: the back-bottom edge's middle is covered by the top face
frames 3
expect steps == 8
expect volume ~ 10.22278
expect xray == 0
key 2
expect pick-mode == 2
move world 2.0 2.5 0.0
frames 2
expect hover lacks Side(Line3)

# ② box over the whole bracket without x-ray: only the 17 visible edges — the 7 hidden ones are the back-bottom, left-bottom
#    and back-left edges, the hole's bottom circle and its seam (on the wall facing away), and the chamfer's two ends on the
#    hidden left / back faces
drag Left viewport 0.01 0.06 by 3000 2000 12
frames 2
expect box-edges == 17
expect selected-edges == 17
expect selected-edges lacks Edge(Extrude#2.Cap(Start)|Extrude#2.Side(Line3))
capture 146XRayBoxOpaque
key Escape
expect selected-edges == 0

# ③ Alt+Z: ghost faces, hidden edges pale; the same box now takes all 24 edges
key Z Alt
frames 2
expect xray == 1
expect surfaces == 1
expect status contains X-ray on
drag Left viewport 0.01 0.06 by 3000 2000 12
frames 2
expect box-edges == 24
expect selected-edges == 24
expect selected-edges contains Edge(Extrude#2.Cap(Start)|Extrude#2.Side(Line3))
capture 147XRayBoxThrough
key Escape
expect selected-edges == 0

# ④ hover through the solid: the hidden back-bottom edge is under the pointer (hover tint, pill names it)
move world 2.0 2.5 0.0
frames 2
expect hover == Edge(Extrude#2.Cap(Start)|Extrude#2.Side(Line3))
capture 148XRayHover

# ⑤ click picks it
click world 2.0 2.5 0.0
frames 2
expect selected-edges == 1
expect selected-edges contains Edge(Extrude#2.Cap(Start)|Extrude#2.Side(Line3))
capture 149XRayPicked

# ⑥ B fillets the hidden edge: the preview is seen through the ghost faces; Enter applies r 0.25
#    (one more face; the volume drops by (1 − π/4) · 0.25² · 4 = 0.053650 → 10.16913)
key B
frames 2
expect bevel-active == 1
expect bevel-chamfer == 0
expect bevel-size ~ 0.25
expect preview-faces == 12
capture 150XRayFillet
key Enter
frames 2
expect bevel-active == 0
expect steps == 9
expect faces == 12
expect sound == 1
expect volume ~ 10.16913
capture 151XRayFilleted

# ⑦ mode 3 faces are not picked through: a spot on the hidden back-bottom line selects the top face in front
#    (at x = 2 the eye ray would enter the hole and meet its wall; at x = 1 it meets the top face)
key Escape
key 3
expect pick-mode == 3
click world 1.0 2.5 0.0
frames 2
expect selected-faces == 1
expect selected-faces contains Cap(End)
expect selected-edges == 0
key Escape

# ⑧ the toolbar toggle turns x-ray off: the hidden edge is no longer under the pointer
key 2
click @XRayToggle
frames 2
expect xray == 0
move world 2.0 0.5 0.0
frames 1
move world 2.0 2.5 0.0
frames 2
expect hover lacks Side(Line3)
key Z Ctrl
frames 2
expect steps == 8
expect volume ~ 10.22278
