# SolidArc multi-body walkthrough — several bodies per document, one matcap per body (step B of the matcap plan).
# Construct's R / "New body" adds a separate body; mode 4 picks whole bodies (Shift adds, pick order = Boolean order); M
# with bodies picked dresses each body; Q opens the Boolean card (Q union · W difference · E intersect · Enter applies).
# The first picked body is the target: it keeps its key, matcap and history; the tools are consumed.
# Run: SolidArcCapture --specimen --reset-files --recovery …/MultiBodyRecovery.solidarc
#      --document …/MultiBody.solidarc --script Exhibits/SolidArc/Code/Scripts/MultiBodyWalkthrough.txt
