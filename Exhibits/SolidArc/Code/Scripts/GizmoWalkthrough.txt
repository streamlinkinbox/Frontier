# SolidArc gizmo walkthrough — the Slate GizmoPRO gizmo on the selection: cones move along an axis, squares move in a
# plane, arcs rotate, cylinders scale, the white ring moves in the screen plane (or scales uniformly with scale alone).
# Modes combine freely (Move / Rotate / Scale chips, y cycles off → T → R → S → T+R → R+S → T+R+S). Bodies take Transform
# steps, faces take face operations (z cone = push / pull, other moves tweak, arcs rotate, ring scales), sketches move as
# loft sections. Snapping is on (0.1 · 5° · ×0.1); Ctrl drags free. Release commits one command, Esc cancels.
# Run: SolidArcCapture --specimen --reset-files --recovery …/GizmoRecovery.solidarc
#      --document …/Gizmo.solidarc --script Scripts/GizmoWalkthrough.txt
# Closed forms: box 2 × 1.5 × 1 = 3; a move or a rotation keeps 3.

# Placement snapped to the 0.1 grid, as these checks were written for (free placement is the default since ⑮ of Snapping).
snap grid on

# ① a box drawn from the Construct menu (2 × 1.5 × 1, a new body)
key N Ctrl
frames 3
click @ConstructLauncher
frames 2
click @ConstructBlock
frames 2
click world -2.0 -1.5 0.0
frames 2
move world 0.0 0.0 0.0
frames 2
click world 0.0 0.0 0.0
frames 2
move world 0.0 0.0 1.0
frames 2
click world 0.0 0.0 1.0
frames 3
expect bodies == 1
expect volume ~ 3

# ② body mode, pick it: the move gizmo (default) sits on the body centre
key 4
frames 1
click world -1.0 -0.7 1.0
frames 3
expect selected-bodies == 1
expect gizmo-target == 2
expect gizmo-modes == 1
capture 218GizmoMove

# ③ drag the z cone up: one Move step, volume kept
drag left @GizmoTranslateZ by 0 -60 12
frames 3
expect gizmo-commits == 1
expect volume ~ 3
expect refused == 0

# ④ y five times: off → … → move + rotate + scale (all three handles at once)
key Y
key Y
key Y
key Y
key Y
frames 2
expect gizmo-modes == 7
capture 219GizmoCombined

# ⑤ the z arc turns the body (5° steps), the x cylinder stretches it along x
drag left @GizmoRotateZ by 40 25 12
frames 3
expect gizmo-commits == 2
expect volume ~ 3
drag left @GizmoScaleX by 30 10 10
frames 3
expect gizmo-commits == 3
expect volume > 3
capture 220GizmoScaled

# ⑥ undo the three, face mode on the top: move + rotate + scale on a face

expect volume ~ 3
key 3

frames 3

expect gizmo-target == 1

# ⑦ push / pull: the face's z cone (its normal) offsets the top up
drag left @GizmoTranslateZ by 0 -50 10
frames 3

expect volume > 3
expect refused == 0
