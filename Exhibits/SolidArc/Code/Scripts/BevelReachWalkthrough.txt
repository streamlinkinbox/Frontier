# SolidArc bevel reach walkthrough — the reports "bevel … seems to be clamped whilst it can bevel more … the cube if
# bevel 1 edge fully it would bevel till the next edge making it a triangle" and "it suppose to go longer even if i put
# a value greater it refuses to bevel any more … this is a cube theres no funny shapes". The size was held at the width
# of the faces beside the edge (first 0.999 of it): wrong twice — past it the blend runs on over the next face (the
# modeller builds that overflow exactly), and at an obtuse edge a fillet's radius is far more than its setback (135°
# faces: r · tan 22.5° = 0.41 r). The size now runs until the modeller refuses (the bound search), at most to a setback
# of the body's diagonal.
# Run: SolidArcCapture --specimen --reset-files --recovery …/BevelReachRecovery.solidarc
#      --document …/BevelReach.solidarc --script Exhibits/SolidArc/Code/Scripts/BevelReachWalkthrough.txt
# Closed forms (2 m cube, unit-cube values · 8): fillet 2 leaves a quarter cylinder 2π; chamfer 2 the triangular prism
# 4; chamfer 3 keeps 8 · ½ (2 − 1.5)² = 1; fillet 3 keeps 4.363248321487495; chamfer 1 then fillet 2.4 on the 135° edge
# keeps 7 − 2 · 2.4² (tan(π/8) − π/8) = 6.752153182631247.
