# SolidArc editing walkthrough — the Plasticity editing keys: G / R / S (move / rotate / scale with X / Y / Z axis,
# Shift+X / Y / Z plane, typed values), Shift+D (duplicate, then move), Ctrl+C / Ctrl+V (paste the body as it stood when
# copied, even after X), H / Shift+H / Alt+H / Ctrl+H (hide selected / unselected, unhide all, invert), J (join touching
# sketches), O (offset curve) and P (pipe).
# Run: SolidArcCapture --specimen --reset-files --recovery …/EditingRecovery.solidarc
#      --document …/Editing.solidarc --script Exhibits/SolidArc/Code/Scripts/EditingWalkthrough.txt
