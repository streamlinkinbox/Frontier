# SolidArc object-snapping walkthrough — the Plasticity point picker while drawing and moving: endpoint,
# midpoint, centre, tangent and perpendicular snaps land on the exact carriers; n / b / t / x / y / z lock a direction
# through the last point; s squares a rectangle; a dragged sketch point (K) and G's grab point land on snaps; x-ray
# reaches hidden points. Object snaps act only while Ctrl is held (the moves and clicks below carry it); without Ctrl the
# pointer keeps the 0.1 grid, and the direction locks slide in 0.1 steps.
# Run: SolidArcCapture --specimen --reset-files --recovery …/SnapRecovery.solidarc
#      --document …/Snap.solidarc --script Exhibits/SolidArc/Code/Scripts/SnappingWalkthrough.txt
# Bracket specimen: block 4 × 2.5 × 1 with its corner at the origin, boss, hole, Fillet1, Chamfer1 — volume 10.22278.
# Closed forms: circle C = (−2, 1.2), r 0.6; from P = (0, 0) the tangent point is C + r(cos α û + sin α ẑ × û) with
# cos α = r / |P − C|: T = (-1.569338679, 1.617768868); the perpendicular foot from (2, 0) is C + r (M − C) / |M − C|
# = (-1.425304229, 1.027591269).

# Placement snapped to the 0.1 grid, as these checks were written for (free placement is the default since ⑮ of Snapping).
snap grid on

click world -2.0 1.2 0.0
frames 2
