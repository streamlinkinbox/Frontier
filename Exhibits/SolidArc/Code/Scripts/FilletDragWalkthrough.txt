# SolidArc fillet drag + orientation cube walkthrough — the Windows report: on a rectangle with all four corners
# filleted, dragging a fillet's points in mode 1 turned the bottom-left arc inside out (the tangent circle swept the long
# way, ~270°). Tangency at a shared endpoint now keeps the side it starts on, and a drag that would still invert a fillet
# is refused (the sketch stays). The orientation cube follows the viewport projection (Parallel / Perspective).
# Run: SolidArcCapture --specimen --reset-files --recovery …/FilletDragRecovery.solidarc
#      --document …/FilletDrag.solidarc --script Exhibits/SolidArc/Code/Scripts/FilletDragWalkthrough.txt
