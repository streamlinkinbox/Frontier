# SolidArc sketch-drawing walkthrough — Plasticity drawing keys on the construction plane, then E extrudes the drawn
# profile with the extrude Boolean keys (q union · w difference · e intersect · r new body).
# Run: SolidArcCapture --specimen --reset-files --recovery …/SketchRecovery.solidarc
#      --document …/Sketch.solidarc --script Scripts/SketchDrawingWalkthrough.txt
# Clicks name world points on z = 0 in the Top view; the pointer snaps to the 0.1 grid, so every profile is exact. A
# first click over the box lands on its top face (z 1.5): the sketch plane follows the face, and a cut goes in (−).
# Closed forms: box 2 × 1 × 1.5 = 3 · hole r 0.4 through: −0.24π · triangle (1.5,0) (3,0) (1.5,1) height 1 outside the
# box: +1/3 · closed Hermite through (0.2,0.2) (0.5,0.2) (0.5,0.8) (0.2,0.8) has area 0.246, pocket 0.5 deep (from the
# top face): −0.123.

# The Drawing options panel, shown by default while a drawing tool is active, covers the top right of the
# viewport where some of these clicks land: hide it first (Inspector › Surface tracing › Drawing options).
frames 2
click @DrawingOptions
frames 2

# Placement snapped to the 0.1 grid, as these checks were written for (free placement is the default since ⑮ of Snapping).
snap grid on
