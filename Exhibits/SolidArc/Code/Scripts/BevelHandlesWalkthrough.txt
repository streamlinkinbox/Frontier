# SolidArc bevel handles walkthrough (Plasticity's pull / push fillet controller) — B on an edge shows a uniform handle
# at mid-edge and one per corner along the outward bisector; dragging a handle sets the size with more control than the
# pointer (Shift fine), a corner handle gives that corner its own size (a variable fillet), the card types them. The bevel
# shows at once: the start size fits the edges, a left drag on empty space adjusts it, a click off an edge keeps the pick,
# and an oversized size keeps showing the last good preview.
# Run: SolidArcCapture --specimen --reset-files --recovery …/BevelHandlesRecovery.solidarc
#      --document …/BevelHandles.solidarc --script Scripts/BevelHandlesWalkthrough.txt
# Closed forms (2 m cube, z 0 … 2): fillet r on one edge removes (1 − π/4) · r² · 2 → r 0.25: 7.973174770424681.

# Placement snapped to the 0.1 grid, as these checks were written for (free placement is the default since ⑮ of Snapping).
snap grid on

# ① a 2 m cube from the Construct menu
key N Ctrl
frames 3
click @ConstructLauncher
frames 2
click @ConstructBlock
frames 2
move world -1.0 -1.0 0.0
frames 2
click world -1.0 -1.0 0.0
frames 2
move world 1.0 1.0 0.0
frames 2
click world 1.0 1.0 0.0
frames 2
move world 1.0 1.0 2.0
frames 2
click world 1.0 1.0 2.0
frames 3
expect refused == 0
expect volume ~ 8

# ② edge mode, the top front edge (y = −1, z = 2), B: 0.25 fits (span 2 → fitted 0.2; 0.25 ≤ 0.35 · 2) and the preview
#    is there without any pointer hunting; three handles (uniform + 2 corners)
key 2
frames 2
click world 0.0 -1.0 2.0
frames 2
expect selected-edges == 1
key B
frames 8

expect bevel-corners == 0
expect bevel-refusal == 0
expect bevel-preview-volume ~ 7.973174770424681

# ③ a click on empty space keeps the picked edge (it used to clear it); the pointer on its way there only shrinks the
#    size (floor 1 mm, it no longer flips into a chamfer); a left drag on empty space sizes it and pins it

expect selected-edges == 1

expect bevel-chamfer == 0

expect bevel-refusal == 0
