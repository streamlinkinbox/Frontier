# SolidArc construct-drawing walkthrough — the Construct menu (Solids · Sketch, 4 × 2 tiles each) starts a drawing command
# in the viewport: plane clicks on the ground (or on a body top), then the pointer lifts the height; live dimension lines
# show W / D / H / R / Ø while drawing. Every solid lands as its own body (R, new body, is the default — no Boolean).
# Run: SolidArcCapture --specimen --reset-files --recovery …/ConstructRecovery.solidarc
#      --document …/Construct.solidarc --script Scripts/ConstructDrawingWalkthrough.txt
# Clicks name world points; plane points snap to the 0.1 grid and heights to 0.1 steps, so every volume is exact.
# Closed forms: box 2 × 1.5 × 1 = 3 · cylinder r 0.5 h 1.2 = 0.3π · cone r 0.6 h 1 = 0.12π · 7-prism R 0.6 h 0.8 =
# 3.5 · 0.36 · sin(2π/7) · 0.8 · torus R 1 r 0.3 = 2π² · 0.09 · box on the first box's top 1 × 0.5 × 0.5 = 0.25.

# Placement snapped to the 0.1 grid, as these checks were written for (free placement is the default since ⑮ of Snapping).
