# SolidArc orient-to-faces walkthrough — a sketch or a Construct solid drawn on a body face takes that face's orientation
# by itself (no Ctrl): the drawing plane is the face (curved faces: the tangent plane at the pointer) and a solid's height
# runs along the outward normal. The Snaps card's "Orient to faces" toggle (on by default) falls back to the grid plane.
# Run: SolidArcCapture --specimen --reset-files --recovery …/OrientRecovery.solidarc
#      --document …/Orient.solidarc --script Scripts/OrientWalkthrough.txt
# Face frames: n̂ outward, x̂ = ẑ × n̂, ŷ = n̂ × x̂; points snap to the 0.1 grid of the face, so every volume is exact.
# Closed forms: cube 2³ = 8 · circle r 0.4 on its +x face extruded 1 = 0.16π · cylinder r 0.4 h 0.5 on the −y face =
# 0.08π · wedge 2 × 2 × 1 = 2 · cylinder r 0.3 h 0.5 on the wedge's slope (n̂ = (1, 0, 2)/√5) = 0.045π.

# Placement snapped to the 0.1 grid, as these checks were written for (free placement is the default since ⑮ of Snapping).
snap grid on

# ① a 2 m cube from the Construct menu; Orient to faces starts on
key N Ctrl
frames 3
expect face-orient == 1
click @ConstructLauncher
frames 2
click @ConstructBlock
frames 2
move world -1.0 -1.0 0.0
frames 2
click world -1.0 -1.0 0.0
frames 2
move world 1.0 1.0 0.0
frames 2
click world 1.0 1.0 0.0
frames 2
move world 1.0 1.0 2.0
frames 2
click world 1.0 1.0 2.0
frames 3
expect refused == 0
expect bodies == 1
expect volume ~ 8
