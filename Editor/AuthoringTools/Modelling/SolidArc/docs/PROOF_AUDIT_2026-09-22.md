# SolidArc proof audit — 2026-09-22

This audit separates three different things that had been conflated:

1. a verifier source exists;
2. the verifier is executed by `Tools/Build/CheckSolidArc.sh`;
3. a visual PNG is persisted in `Proofs/`.

A source verifier alone is not a durable visible proof, and a new verifier that repeats the
same fixture and assertions is not a new capability.

## Duplicate removed

`VariableRadiusRootBlendVerification`/Phase 36t was a duplicate of
`Phase33VariableRadiusVerification`/Phase 36e. It used the same endpoint supports, same linear
law, same frustum reconstruction, same topology/volume/refusal assertions, and only changed the
method name and camera. The Phase 36t alias, verifier, plan, and PNG were removed. Phase 36e
remains the proof of the **linear ruled/frustum foundation**.

That foundation is **not** proof of a rolling-ball variable-radius fillet. The following remain
unproved and intentionally unsupported: variable-radius rolling fillets, variable setbacks,
partial-edge blends, nonlinear laws, and G2 continuity.

## Current Phase 34–36 coverage

These are distinct routes, not duplicates:

- 34a–34f: face lofts, tweaks, direct chamfers, and connected/general face routes;
- 35a–35d: curved tweaks, concave/native chamfer networks, and connected cap loft;
- 36a–36e: face editing, general connected/curved routes, non-planar loop chamfer, and the
  linear variable-radius foundation;
- 36f–36n: complete/partial plane–cone, cylinder–cone, cone–cylinder, cone–cone, and apex
  **chamfer** routes;
- 36o–36s: partial plane–cone, complete cylinder–cone, complete cone–cone, partial cone–cone,
  and partial cone–cylinder **fillet** routes.

The Phase 36s visual proof is the corrected exterior-facing proof; it is not a substitute for
other route families.

## Existing verifier coverage not in the current direct gate

The current `CheckSolidArc.sh` loop runs 29 focused tests. It does not run these older, distinct
fillet/chamfer baselines:

- Phase 25 cylinder chamfer;
- Phase 26 cylinder fillet;
- Phase 31 plane–cylinder fillet;
- Phase 32a tangent-chain fillet;
- Phase 32b finite open-chain fillet;
- Phase 32c multi-edge fillet;
- Phase 32d general-angle sector endpoint fillet;
- Phase 32e corner fillet;
- Phase 32z complete plane–cone fillet.

On this audit date, each of those nine verifier sources was compiled and run independently; each
reported `0 failed`. Their PNGs are generated by the verifiers but are not currently tracked in
this checkout, so they are source-level/standalone proofs rather than persisted visible proof
artifacts.

Many older CMake verification targets for bores, pushes, booleans, constraints, dimensions,
and the Phase 10 suite are likewise not in the focused direct gate. They should not be described
as newly proven by a Phase 36 proof.

## Actual remaining proof/capability gaps

1. The general rolling-ball variable-radius application is still bounded: Stage 37a now covers
   only one finite straight planar corner with a linear law. General edge selection, curved
   roots, and support-specific variable rolls remain open.
2. Variable setback laws, partial-edge blends, nonlinear radius laws, and G2 continuity.
3. Complete and partial apex **fillets**; only apex chamfers are covered.
4. Broader flaring/narrowing and mixed-support combinations outside the explicitly accepted
   constant-radius routes.
5. Non-coaxial/oblique/freeform supports, arbitrary curved edge loops, corner patches, and
   general intersection/trim/sew healing.
6. Durable PNG artifacts for the older Phase 25/26/31/32/32z verifier family if those are part
   of the required visible-proof set.

## Next work rule

Do not add another verifier merely by renaming an existing fixture. Pick one item from the
actual gap list, write its bounded plan first, implement the smallest distinct route, and add
one visual proof that demonstrates geometry not already shown by an existing image.
