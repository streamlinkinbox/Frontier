Load return (how the CPU sees the physics)

The reduction and the hub integration run on the GPU, so the load never has to come back to the CPU for physics. The host copies one 128-byte block per frame into a 3-slot staging ring and maps it asynchronously. The render loop never waits on it, so the readback age above is the telemetry delay.
